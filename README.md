# Links

Personal golf handicap tracker (WHS index, scoring record, trends, saved courses).

Live at https://bjeisenberg11.github.io/Links/

- `index.html` – the app (Firebase Firestore for sync)
- `seed.json` – GHIN score history, loaded automatically on first launch

## Claude insights

`insights.json` holds the "Claude's take" card on Overview. Ask Claude to "refresh Links insights" to rewrite it from your latest rounds.
